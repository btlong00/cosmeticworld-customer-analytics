# 📁 Dataset Directory

This folder is designated for storing the project's source dataset. Due to storage optimization and file structure requirements, the full dataset consists of multiple CSV files hosted externally.

### 📥 Download Link
You can download the official dataset folder containing all required CSV files here:
👉 [Download CosmeticWorld Dataset Folder from Google Drive](https://drive.google.com/drive/folders/1ZXvbpsIl7meF6TfIcamkp-dnVobjnBVa?usp=sharing)

### 📊 Dataset Structure
The dataset includes the following 4 files:
* `EcomSales.csv` — Transaction and sales records (OrderID, Sales, Profit, Quantity, etc.).
* `Customer.csv` — Customer demographic information (CustomerID, Income, Occupation, etc.).
* `Product.csv` — Product metadata (ProductCode, Product Name, Category, Subcategory).
* `Region.csv` — Geographical mapping (RegionCode, City, State, Country, Market).

### ⚙️ Setup Instructions
1. Click the link above to access the Google Drive folder.
2. Download all 4 CSV files (`EcomSales.csv`, `Customer.csv`, `Product.csv`, `Region.csv`).
3. Place all downloaded files directly into this `Dataset/` directory.
4. Ensure the exact file names are preserved so that analytical scripts and data pipelines can properly load and join the data tables.
